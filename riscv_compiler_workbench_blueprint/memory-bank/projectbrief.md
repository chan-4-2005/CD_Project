# Project Brief

Build RISC-V Compiler Research Workbench: a premium hosted application for genuine, limited GCC-versus-LLVM RISC-V experiments, compiler inspection, comparison, and reproducible report sharing.

Constraints: free tiers only; 2–3 day MVP target; Windows laptop with 8 GB RAM; no physical RISC-V hardware; friends can sign in and run limited jobs; private by default; explicit report sharing.

Non-negotiable: no fabricated measurements, no arbitrary shell execution, no unverified hardware claims, and no implementation until explicitly authorized.
